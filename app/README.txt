VKonvert 2.0 - convert, compress and combine images and PDFs
=============================================================
Made by Vishnu VK · Made with Claude Code · Free to use (MIT License)
Website: https://vkonvert.com

INSTALL
1. Double-click VKonvert-Setup-2.0.exe.
   If Windows shows "Windows protected your PC", click More info > Run anyway.
2. Read and accept the license, choose the folder and options, click Install.
   No admin rights needed.
3. Click Finish. VKonvert is in the Start menu and in Settings > Apps.
   To update later, run a newer VKonvert-Setup over it.

PORTABLE VERSION
  Using VKonvert-2.0-Portable.zip? Unzip it anywhere and run VKonvert.exe.
  Nothing is installed: no shortcuts, no right-click menu. Delete the folder to remove it.

THE TOOLS
  Pictures:  Convert · Compress · Resize · Remove photo info
  PDF:       Images to PDF · Merge · Split · Compress · PDF to images ·
             Rotate & reorder · Protect with a password

  Drop files on the window (or click "+ Add"), pick a tool at the top, press the
  red button. New files appear on the right; double-click one to open it.
  Originals are never changed or overwritten ("photo (1).jpg" instead).

RIGHT-CLICK MENU
  Right-click a picture or PDF > VKonvert > pick a tool, or "Convert to JPG" etc.
  Windows 11: the menu is under "Show more options" (or Shift + right-click).

FORMATS
  Opens:     JPG, PNG, WebP, HEIC/HEIF, AVIF, GIF, TIFF, BMP, ICO, TGA, PSD, PDF
  Saves as:  JPG, PNG, WebP, AVIF, HEIC, PDF, ICO, GIF, TIFF, BMP

  Saving HEIC uses Windows' own codecs: "HEIF Image Extensions" and
  "HEVC Video Extensions" from the Microsoft Store. VKonvert tells you if they're missing.

LIGHT AND DARK
  The sun/moon button at the top right switches. The ••• menu > Appearance
  can also follow your Windows setting.

UNINSTALL
  Settings > Apps > Installed apps > VKonvert > Uninstall
  (or in VKonvert: ••• > Uninstall VKonvert). Your files are not touched.

UPGRADING FROM VPIX OR VPIXSHIFT
  Installing VKonvert removes the older Vpix / VPixShift (menus, shortcuts, files).

PRIVACY
  Everything happens on your PC. VKonvert doesn't upload files or collect data.
  If something goes wrong, details are written to
  %LOCALAPPDATA%\VKonvert\error.log (only on your PC).

REQUIREMENTS
  Windows 10 or 11, 64-bit. If it says the Visual C++ Runtime is missing,
  click Yes to download it from Microsoft, install it, then open VKonvert again.
